# Yeelight Night Mode

Кастомная интеграция для Home Assistant (устанавливается через HACS как
Custom Repository), которая автоматически создаёт `switch`-сущность
"Night Mode" для каждого светильника Yeelight, **если сам светильник
подтверждает поддержку** ночного/moonlight режима.

Не подтверждает поддержку — сущность не создаётся, а не создаётся
"мёртвая" кнопка, которая ничего не делает.

## Как это работает

1. Интеграция берёт все существующие записи (config entries) штатной
   интеграции `yeelight`.
2. Для каждого светильника, по его IP, напрямую по локальному API
   Yeelight запрашивает свойства `active_mode` и `nl_br`.
   Согласно LAN API Yeelight, на неподдерживаемое свойство устройство
   отвечает пустой строкой — так определяется, есть ли у лампы ночник
   (реальный moonlight/nightlight режим есть в основном у моделей
   "ceiling", т.е. потолочных светильников с ночной подсветкой; у
   большинства цветных ламп и лент его физически нет).
3. Если поддержка подтверждена — создаётся сущность ночного режима. При добавлении интеграции можно выбрать способ именования:
   - **ID сенсора ночного режима** — используется часть после точки, например `yeelight_ceila_0x1c56d19c_nightlight`;
   - **ID светильника** — используется часть после точки, например `yeelight_ceila_0x1c56d19c`;
   - **Пользовательское** — произвольная строка с плейсхолдерами `<binary_sensor_id>` и `<light_entity_id>`.
   Выбор также доступен позже в Options.
4. Включение/выключение выполняется через `set_power_mode`
   (`PowerMode.MOONLIGHT` / `PowerMode.NORMAL`) напрямую по локальной
   сети, без облака.
5. Каждые 30 секунд сущность опрашивает лампу и подтягивает актуальный
   режим — если вы переключили ночной режим из приложения Yeelight или
   голосом, тумблер в HA обновится сам (с задержкой до 30 сек).

## Установка через HACS

1. HACS → правый верхний угол (⋮) → **Custom repositories**.
2. Вставьте URL этого репозитория, категория **Integration**, «Add».
3. Найдите **Yeelight Night Mode** в списке интеграций HACS → Install.
4. Перезапустите Home Assistant.
5. Настройки → Устройства и службы → **Добавить интеграцию** → Yeelight Night Mode.
   На странице создания выберите тип сущности и способ именования. Всё остальное определится автоматически по уже настроенным Yeelight-лампам.

> Важно: сначала должна быть настроена штатная интеграция **Yeelight**
> (Settings → Devices & Services → Yeelight), эта интеграция только
> дополняет её.

## Использование

Каждая созданная сущность — обычный `switch`, её можно:

- добавить на дашборд как toggle/entities-карточку;
- сгруппировать через `switch` group / label в UI;
- использовать в автоматизациях (`switch.turn_on` /
  `switch.turn_off`), например «включать ночной режим в 23:00 и
  выключать в 7:00».

Пример карточки со всеми переключателями ночного режима:

```yaml
type: entities
title: Ночной режим Yeelight
entities:
  - entity: switch.spalnya_night_mode
  - entity: switch.detskaya_night_mode
```

Если хочется единой кнопки "все сразу" — создайте группу:

```yaml
switch:
  - platform: group
    name: "Yeelight Night Mode (все)"
    entities:
      - switch.spalnya_night_mode
      - switch.detskaya_night_mode
```

## Ограничения

- Работает только с лампами, доступными по LAN API (у Yeelight должен
  быть включён режим "LAN Control" в приложении Yeelight/Mi Home).
- Реальный moonlight-режим поддерживают преимущественно потолочные
  светильники серии Ceiling с ночником. У обычных цветных ламп/лент
  сущность создана не будет — это ожидаемое поведение, а не баг.
- Опрос состояния — раз в 30 секунд (не мгновенно), т.к. у Yeelight
  нет пуш-обновлений свойств без включения "музыкального режима"
  (music mode), который занимает соединение и конфликтует с обычным
  управлением.
- Требуется, чтобы устройство было доступно по локальной сети
  (тот же IP, что видит основная интеграция `yeelight`).
