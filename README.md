# Yeelight Night Mode

Кастомная интеграция для Home Assistant, которая добавляет для каждого светильника Yeelight отдельную сущность **Nightlight Mode**, если штатная интеграция Yeelight сообщает о поддержке ночного (moonlight/nightlight) режима.

Интеграция **не создаёт отдельное подключение к лампе для управления**: включение и выключение ночного режима выполняется через штатную интеграцию Home Assistant `yeelight` с помощью action `yeelight.set_mode`.

## Как это работает

1. Интеграция использует уже настроенные устройства штатной интеграции `yeelight`.
2. Для каждого светильника определяется наличие связанного binary sensor ночного режима. Если такой sensor отсутствует, сущность Nightlight Mode для светильника не создаётся.
3. При добавлении интеграции можно выбрать тип создаваемой сущности: **switch** или **light**.
4. Настройка **Entity ID naming** определяет **только Entity ID (object ID) новой сущности**. Отображаемое имя каждой созданной сущности всегда **Nightlight Mode**.
5. Для варианта **Night sensor entity ID** используется часть после точки из ID binary sensor.
6. Для варианта **Custom** можно использовать плейсхолдеры:
   - `<binary_sensor_id>` — часть после точки из ID binary sensor ночного режима;
   - `<light_entity_id>` — часть после точки из ID исходной Yeelight light-сущности.

Пример пользовательского шаблона:

```text
<light_entity_id>_night_mode
```

Для исходной сущности `light.ceilb_0x24f96a4f` результатом будет `light.ceilb_0x24f96a4f_night_mode`.

## Управление ночным режимом

При включении/выключении созданная сущность вызывает штатный Home Assistant action `yeelight.set_mode` для исходной Yeelight light-сущности:

- включение — `moonlight`;
- выключение — `normal`.

Таким образом, дополнение не использует отдельный объект `Bulb` и не открывает второе соединение с Yeelight для управления.

## Установка через HACS

1. HACS → правый верхний угол (⋮) → **Custom repositories**.
2. Добавьте URL этого репозитория с категорией **Integration**.
3. Найдите **Yeelight Night Mode** и установите интеграцию.
4. Перезапустите Home Assistant.
5. Настройки → Устройства и службы → **Добавить интеграцию** → **Yeelight Night Mode**.
6. Выберите тип сущности и способ формирования Entity ID.

> Важно: сначала должна быть настроена штатная интеграция **Yeelight**. Это дополнение использует её устройства и управление.

## Использование

Каждая созданная сущность имеет отображаемое имя **Nightlight Mode** и может использоваться в дашбордах и автоматизациях Home Assistant.

Например, при выборе типа `switch` и шаблона `<light_entity_id>_night_mode` для `light.ceilb_0x24f96a4f` будет создана:

```text
switch.ceilb_0x24f96a4f_night_mode
```

При выборе типа `light` для той же настройки:

```text
light.ceilb_0x24f96a4f_night_mode
```

## Ограничения

- Работает только с устройствами, поддерживаемыми штатной интеграцией Home Assistant `yeelight`.
- Созданная сущность появляется только для светильников, для которых доступен binary sensor ночного режима.
- Состояние Nightlight Mode синхронизируется со состоянием binary sensor штатной интеграции.
- Для переключения режима требуется, чтобы исходная `light.*` сущность была доступна и управляема штатной интеграцией Yeelight.
